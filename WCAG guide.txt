Audit the entire website against WCAG 2.2 AA color contrast requirements. Analyze all text, icons, buttons, links, form controls, borders, focus states, and UI components using the existing color palette. Wherever a contrast violation is found, adjust only the affected color(s) just enough to meet the required contrast ratio (4.5:1 for normal text, 3:1 for large text and UI components), while preserving the original hue, saturation, and overall visual identity. Do not redesign, replace, or significantly alter the established color palette—make only the minimum contrast corrections necessary to achieve full WCAG AA compliance.
